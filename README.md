# Prediction@Illinois

Website for Prediction@Illinois — the student research organization for prediction markets at
the University of Illinois Urbana-Champaign.

We research prediction markets end to end — pricing, forecasting, mechanism, application —
across elections, sports, crypto, economics, tech, and weather.

**Fall 2026 applications are open.** Rolling, all majors, no finance background required.

- Site: https://prediction-illinois.github.io
- Contact: see the Join section on the site

## Development

Static single file, no build step. Open `index.html` in a browser.

Deployed with GitHub Pages from the `main` branch.
